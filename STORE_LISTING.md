# Chrome Web Store listing — YouTube Stat Eliminator

## Name
YouTube Stat Eliminator

## Short description (132 chars max)
Hide view counts, like counts, subscriber counts & comment counts on YouTube. Watch videos without the numbers.

## Full description
Tired of view counts deciding what you watch? YouTube Stat Eliminator removes
engagement statistics across YouTube so you can judge videos on their own merits.

HIDES:
- View counts — homepage, search, channel pages, watch pages, Up Next, Shorts
- Like counts — watch page and Shorts
- Subscriber counts — video pages, channel pages, search results
- Comment counts — comment headers and per-comment likes

YOU CONTROL IT:
Each category toggles independently from the toolbar popup, and changes apply
instantly to open tabs. Buttons stay fully functional — only the numbers go away.

PRIVATE BY DESIGN:
No accounts, no analytics, no data collection. Your toggle preferences are the
only thing stored, synced privately through your own Chrome profile.
